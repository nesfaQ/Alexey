# Тестирование интеграции

| Сценарий | Ожидаемый результат |
|---|---|
| Полный проход матрицы через три модуля | Строки обменяны, созданы три XML-файла |
| Пустая и непрямоугольная матрица | Отказ с понятной ошибкой |
| Нечисловое значение в XML | `InvalidDataError` |
| Неверные размеры в XML | `InvalidDataError` |
| Неподдерживаемая версия | `VersionConflictError` |
| Отсутствующий XML-файл | `IntegrationTimeoutError` |
| Недоступный модуль | `ModuleUnavailableError` |
