# Результаты ревью кода

## Сильные стороны

- функции разделены по назначению;
- размеры и элементы матрицы проверяются при вводе;
- алгоритм поддерживает прямоугольные матрицы;
- исходная матрица не изменяется;
- основные сценарии покрыты тестами pytest;
- критические ошибки контролируются flake8.

## Результат

Код соответствует варианту 4: строки, содержащие глобальные минимальный и
максимальный элементы, меняются местами. Если оба экстремума находятся в
одной строке, порядок строк не изменяется.
