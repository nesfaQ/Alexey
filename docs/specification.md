# Техническое задание

Разработать консольную программу обработки вещественной матрицы размером
`n x m`. Программа должна определить глобальные минимальный и максимальный
элементы и поменять местами строки, в которых они расположены.

Размеры должны быть натуральными числами. Каждая строка должна содержать
ровно `m` числовых значений. Ошибочный ввод не должен приводить к аварийному
завершению программы.
