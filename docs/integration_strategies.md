# Сравнение стратегий интеграции

| Стратегия | Преимущества | Недостатки | Когда применять |
|---|---|---|---|
| Нисходящая | Рано проверяется общая логика | Нужны заглушки | Важна управляющая часть |
| Восходящая | Рано проверяются базовые модули | Нужны драйверы | Система зависит от нижнего уровня |
| Сэндвич | Параллельная работа сверху и снизу | Сложнее планировать | Многоуровневые системы |
| Риск-ориентированная | Рано снижает главные риски | Нужна точная оценка рисков | Сложные и критичные проекты |
| Функциональная | Быстро появляется рабочий сценарий | Общие модули могут повторно затрагиваться | Системы с понятными функциями |
| Т-образная | Быстрая проверка вертикального среза | Остальные ветви временно неполны | Микросервисы и прототипы |

Для текущей программы функциональная стратегия даёт сквозную проверку цепочки
"ввод - обработка - вывод" и соответствует варианту 4.
