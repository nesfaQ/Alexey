# Инспекция кода

Проверка выполняется командой `flake8 src tests`. При ревью проверены:

- разделение ответственности между модулями;
- одинаковая валидация данных на всех этапах;
- отсутствие изменения исходной матрицы;
- проверка схемы и версии XML;
- обработка ошибок на границах модулей;
- читаемость и соответствие PEP 8.

Критических замечаний по логике интеграции не выявлено. Статическая проверка включена в CI.
