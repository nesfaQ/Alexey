# Российские аналоги GitHub

## GitFlic

Российская платформа для хранения Git-репозиториев, совместной разработки и
настройки CI/CD. Поддерживает публичные и закрытые проекты.

## GitVerse

Платформа для размещения исходного кода и совместной работы над проектами.
Предоставляет веб-интерфейс, задачи и средства проверки изменений.

## Mos.Hub

Корпоративная платформа для разработки программного обеспечения с
возможностью размещения репозиториев в российской инфраструктуре.

Для учебного проекта выбран GitHub благодаря знакомому интерфейсу и готовой
интеграции с GitHub Actions.
