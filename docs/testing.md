# План тестирования

Автоматические тесты проверяют:

- квадратную и прямоугольную матрицы;
- отрицательные и вещественные значения;
- расположение минимума и максимума в одной строке;
- неизменность исходной матрицы;
- обработку ошибочных размеров;
- контроль количества элементов в строке;
- повторный ввод после нечислового значения;
- формат вывода результата.

Запуск тестов:

```bash
pytest -v
```
