# Архитектура программы

Программа состоит из четырёх независимых функций:

1. `input_matrix_size` проверяет размеры матрицы;
2. `input_matrix` считывает вещественные элементы;
3. `swap_extreme_rows` находит строки глобальных минимума и максимума и
   меняет их местами;
4. `print_matrix` выводит результат.

Функция обработки не изменяет исходную матрицу, а возвращает новую. Это
упрощает тестирование и предотвращает неожиданные побочные эффекты.
