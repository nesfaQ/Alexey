# Перестановка строк вещественной матрицы

Учебный проект для выполнения лабораторной работы по дисциплине
«Инструментальные средства разработки программного обеспечения».

Программа вводит вещественную матрицу размером `n x m`, находит её
глобальные минимальный и максимальный элементы и меняет местами строки,
в которых расположены эти элементы.

Автор: Боцман Алексей Андреевич, группа Т9-ИП-25-2.

## Требования

- Python 3.9 или новее;
- GNU/Linux или Windows.

## Запуск

```bash
python src/main.py
```

Пример исходной матрицы:

```text
3
3
1 2 3
4 5 6
7 8 9
```

Результат:

```text
7.0 8.0 9.0
4.0 5.0 6.0
1.0 2.0 3.0
```

## Проверка

```bash
pytest -v
```

## Ветвление

Стабильная версия хранится в ветке `main`, разработка ведётся в ветке
`develop`. Изменения проверяются GitHub Actions и после проверки
объединяются с основной веткой.
