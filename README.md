# Обмен строк по минимальному и максимальному элементам

Консольная программа для варианта 4. Пользователь задаёт количество строк
и столбцов, а затем вводит вещественную матрицу. Программа определяет, в
каких строках находятся наименьший и наибольший элементы всей матрицы, и
меняет эти строки местами.

## Как работает алгоритм

1. Проверяются размеры матрицы.
2. Каждая строка считывается отдельно.
3. Определяются строки глобального минимума и максимума.
4. Найденные строки меняются местами.
5. Полученная матрица выводится в консоль.

Если оба экстремальных элемента находятся в одной строке, матрица остаётся
без изменений.

## Пример

Для матрицы:

```text
3 2
4.5 -8
1 12
3 6
```

результат будет следующим:

```text
1.0 12.0
4.5 -8.0
3.0 6.0
```

## Запуск программы

Требуется Python версии 3.9 или новее.

```bash
python src/main.py
```

## Проверка проекта

```bash
pytest -v
```

Проект содержит восемь автоматических тестов. Дополнительно GitHub Actions
запускает проверку для Python 3.9, 3.10, 3.11 и 3.12.

## Организация разработки

Готовая версия хранится в `main`, текущая разработка выполняется в
`develop`. Перед слиянием изменения проходят автоматическую проверку.
