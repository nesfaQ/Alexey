# Обработка матрицы с XML-интеграцией

Консольная программа для варианта 4. Пользователь задаёт количество строк
и столбцов, а затем вводит вещественную матрицу. Программа определяет, в
каких строках находятся наименьший и наибольший элементы всей матрицы, и
меняет эти строки местами. В третьей лабораторной работе
ввод, обработка и вывод разделены на модули. Данные между этапами
передаются через XML-файлы версии 1.0.

## Модули

- `input_module` считывает и проверяет матрицу;
- `processing_module` меняет строки с глобальными экстремумами;
- `output_module` форматирует результат;
- `xml_transport` записывает и читает XML-сообщения;
- `integration` объединяет все этапы в общий конвейер.

Если оба экстремальных элемента находятся в одной строке, матрица остаётся
без изменений.

## Пример

Для матрицы:

```text
3 2
4.5 -8
1 12
3 6
```

результат будет следующим:

```text
1.0 12.0
4.5 -8.0
3.0 6.0
```

## Запуск программы

Требуется Python версии 3.9 или новее.

```bash
python -m src.main
```

## Проверка проекта

```bash
python -m pip install -r requirements-dev.txt
pytest -v
pytest --cov=src --cov-report=term-missing --cov-fail-under=90
flake8 src tests
```

GitHub Actions запускает обычные и интеграционные тесты, линтер и проверку
покрытия. Описание интеграции находится в [`docs/integration.md`](docs/integration.md).
